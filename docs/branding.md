# Buffer logo

`_assets/icon.svg` is a green variant prepared for this integration at the user's
request. It preserves the exact three-layer mark from Buffer's official SVG
favicon, with padding on a rounded green background. `_assets/icon.png` is its
256 × 256 pixel rendering used by the plugin.

Mark source: https://buffer.com/icons/favicon.svg

The mark is linked by Buffer's official website: https://buffer.com/press

The colors are sampled from the user's reference image supplied on October 16,
2026: dark green background `#2D3E3E` and light green mark `#BDEBA5`.

This is an integration-specific composition, not an unchanged official asset.
